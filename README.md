\# BudgetBliss Events



\*\*BudgetBliss Events\*\* is a native Android event-planning application designed to simplify the organization of weddings, birthdays, corporate functions, and other events.



The platform connects event planners with vendors and brings vendor discovery, real-time price negotiation, budget management, scheduling, communication, and service booking into a single mobile application.

\## 🏗️ Architecture



BudgetBliss Events is a native Android application backed by Firebase services.



The application provides separate workflows for event planners and vendors. Cloud Firestore enables real-time synchronization for features such as communication and price negotiation, while local Android storage technologies are used where appropriate for application data and preferences.



\---



\## 💰 Real-Time Price Negotiation



One of the core features of BudgetBliss Events is direct price negotiation between users and vendors.



Vendors can list their services and pricing, while users can submit offers. Vendors can respond to those offers, allowing both parties to negotiate service pricing directly through the application.



Cloud Firestore real-time synchronization allows negotiation updates to be reflected without requiring manual page refreshes.

\## 🚀 Running the Project Locally



\### Requirements



\- Android Studio

\- Android SDK

\- JDK

\- Android Emulator or physical Android device

\- Firebase configuration for cloud-dependent functionality



\### Setup



1\. Clone this repository.



2\. Open the project in \*\*Android Studio\*\*.



3\. Configure the required Firebase services.



4\. Add your Firebase configuration file to:



&#x20;  `app/google-services.json`



5\. Configure the required Google Maps credentials.



6\. Sync the project with Gradle.



7\. Select an Android emulator or connect a physical Android device.



8\. Run the application from Android Studio.



> Firebase configuration and machine-specific files are intentionally excluded from this repository.
